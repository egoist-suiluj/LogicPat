Simulan natin sa Programming

Boss, pag-aaralan natin ang programming.

Pero hindi muna tayo gagamit ng command line o anumang code sa ngayon, dahil ang mga iyon ay programming-specific at may sarili silang set of rules na medyo mahirap intindihin sa simula. May kanya-kanya rin silang use case depende sa problemang sinusolusyunan nila.

Sa ngayon, hindi muna natin iyon papasukan. Ang goal natin, boss, ay makabuo muna ng solid na foundation at mas maunawaan kung ano ba talaga ang programming.

Ano nga ba ang programming?

Sa pagkakaintindi ko, ang programming ay isang set ng instructions na ibinibigay sa computer bilang gabay para sa isang specific na task na gagawin nito.

Sa madaling salita, ang programming ang nag-uutos sa computer kung ano ang dapat nitong gawin para makumpleto ang isang task nang tama at walang sablay.

Ganito, boss: isipin mo na lang na ako ay isang “less than intelligent” na entity na nakaasa lang sa instructions na ibibigay mo.

Inutusan mo akong mag-drawing, pero nawala ko yung instructions na binigay mo. Dahil wala na sa akin ang instructions, hindi ko alam kung saan magsisimula o kung ano ang gagawin ko. Nataranta ako, nag-stress, at hindi ko nagawa yung task. Ayun..! nag error, dahil sa, hindi na alam ang gagawin...

Ang pagbibigay mo sa akin ng instructions ay maihahalintulad sa pagsusulat ng code.

Sa halip na ako—na nakaasa lang sa instructions mo—ang kausap mo, isipin mo na ang kausap mo ay isang computer na limitado ang pag-iisip. Sa halip na drawing instructions, binibigyan mo siya ng step-by-step na proseso kung paano gagawa ng laro o web application.

Dito, boss, mahalagang tandaan na ang computer ay hindi “matalino” sa natural na paraan. Oo, ginawa itong napaka-sopistikado, pero sa core nito, ginagawa lang nito ang eksaktong ipinapagawa natin.

Mas tamang sabihin na: ang computer ay “matalino” dahil pinrograma natin ito para maging ganoon.

Ngayon, hindi ganoon kadali ang programming gaya ng simpleng pagsasalita ng English o Tagalog.

Ang computer ay hindi natural na nakakaintindi ng mga human language. Sa pinaka-basic na level, machine code lang ang naiintindihan nito—mga 1 at 0 na tinatawag na binary.

Ang bawat instruction na ibinibigay natin sa computer ay kino-convert sa series ng 1 at 0, at iyon ang binabasa at iniintindi nito para magsagawa ng tasks.

Balikan natin yung example kanina.

Kung ako ang “less than intelligent” na nakaasa sa instructions mo, mas lalong limitado ang sitwasyon ng computer. Para bang hindi lang ako hindi marunong mag-isip—hindi ko rin naiintindihan ang Tagalog o English, kundi isang ibang wika lang (halimbawa Japanese o Nihongo).

Kaya kung gusto mong makapagbigay ng instructions, kailangan mo munang i-translate ang lahat ng language mo boss, papunta sa wikang naiintindihan ko.

Napakahirap para sa tao na direktang magsulat ng machine code. Kaya sa halip, gumagamit tayo ng programming language.

Ano ang programming language?

Ang programming language ang nagsisilbing tagapamagitan. Siya ang nagta-translate ng instructions na naiintindihan ng tao papunta sa machine code na naiintindihan ng computer.

Mas madali itong intindihin kumpara sa binary, kaya ito ang ginagamit ng mga programmer.

Halimbawa, kung ang instruction ay nasa English o Tagalog, ang programming language ang parang interpreter na nagta-translate nito sa wika ng computer.

Dahil dito, napaka-importante ng programming language sa software development.

Ang Python at Java, halimbawa, ay general-purpose languages na kayang gumawa ng maraming klase ng application. Samantalang ang HTML at CSS ay mas specific—ginagamit para sa website structure at design.

Nagkakaiba rin ang programming languages sa performance at level ng abstraction.

Halimbawa, ang JavaScript ay kadalasang ginagamit para sa smaller tasks o interactivity sa web, habang ang Java at Python ay ginagamit para sa mas malalaking systems at mas complex na computations.

Pwede rin nating ilarawan ang “lapit” ng programming language sa machine code.

Ang low-level languages tulad ng Assembly at C ay mas malapit sa machine code, kaya mas mabilis silang i-execute ng computer.

Ang high-level languages tulad ng Python at Java ay mas malayo sa machine code, kaya mas maraming layer ng translation ang nangyayari, pero mas madali naman silang basahin at gamitin.

Ang Assembly language ay isang low-level programming language na pinakamalapit sa machine code. Ito ay direktang nauunawaan ng CPU gamit ang mnemonics na kumakatawan sa basic instructions tulad ng paglipat ng data at pag-compute. Dahil sa pagiging malapit nito sa hardware, nagbibigay ito ng mataas na performance at kontrol sa system resources. Gayunpaman, mahirap itong matutunan at gamitin dahil sa komplikadong syntax at kakulangan ng abstraction. Karaniwang ginagamit ang Assembly sa firmware, device drivers, at embedded systems kung saan mahalaga ang bilis at efficiency.

Samantala, ang C language ay itinuturing na middle-level language dahil pinagsasama nito ang low-level control at high-level readability. Mas madaling gamitin ang C kumpara sa Assembly, ngunit nagbibigay pa rin ito ng access sa memory at hardware manipulation. Ito ay isa sa mga pinakaginagamit na wika sa pagbuo ng operating systems, embedded systems, at performance-critical applications. Dahil sa efficiency nito, nananatiling mahalaga ang C sa larangan ng systems programming.

Ang Python naman ay isang high-level programming language na kilala sa simplicity at readability nito. Ang syntax nito ay madaling maintindihan, kaya ito ay popular sa mga beginners at professionals. Hindi tulad ng Assembly at C, ang Python ay mas nakatuon sa mabilis na development kaysa sa performance. Ito ay malawakang ginagamit sa data analysis, artificial intelligence, machine learning, web development, at automation. Dahil sa dami ng built-in libraries at frameworks, pinapadali nito ang pagbuo ng complex applications.

Sa kabilang banda, ang Java ay isang high-level, object-oriented programming language na dinisenyo para maging portable at scalable. Ito ay tumatakbo gamit ang Java Virtual Machine (JVM), na nagbibigay-daan upang ang isang program ay gumana sa iba’t ibang platform nang hindi binabago ang code. Kilala ang Java sa pagiging structured at secure, kaya madalas itong ginagamit sa enterprise systems, banking applications, at Android development. Bagama’t mas verbose ito kumpara sa Python, nagbibigay naman ito ng mas mahigpit na control sa program structure.

Sa madaling sabi:

Low-level = mas mabilis, mas mahirap intindihin

High-level = mas madaling intindihin, mas maraming abstraction

Sa huli, ang pagpili ng programming language ay depende sa goal mo bilang programmer. Kadalasan, pare-pareho lang ang capability nila—nagkakaiba lang sa paraan ng pagsulat at gamit.
