Eto boss, kaunting example ng logic gates at kung pano sila gumagana.

🔷 AND Gate

A = True

B = True

Output: True

Both conditions are satisfied.

🟢 OR Gate

A = True

B = False

Output: True

At least one condition is satisfied.

🔴 NOT Gate

Input = True

Output: False

The input value is reversed.

A B Output
True True True
